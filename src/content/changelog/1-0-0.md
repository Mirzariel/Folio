## What ships

- A gallery of every photograph and video in the locations you add, several at once, with a
  timeline of when they were taken.
- Adding a location by dropping a folder on one of the three doors, and Check for changes to
  scan it again.
- Scanning and identification you can stop and resume, even after closing Folio.
- Exact duplicates, judged on content, page by page for large archives. Let Folio choose keeps
  exactly one copy of each photograph, and a copy you mark Keep as backup is never offered for
  removal.
- Cleanup through the Windows Recycle Bin, never a permanent deletion.
- Rename in bulk, with every new name shown first, three separators, and numbering per file
  type. Extensions are kept.
- Organize by capture date in four folder styles, optionally sending folders left empty to the
  Recycle Bin.
- Choosing photographs by hand for Organize and Rename: a list you can scroll, search and filter,
  with any number chosen.
- Organize by date and Rename also work on exFAT and FAT32 drives, where Folio proves each file
  by its content instead of a file id. Cleanup is still refused there.
- Import from a camera card: copy or move what is new, organized by date, with the destination
  asked each time (or saved in Settings). The same card plugged in again shows only what is new.
  Files with no capture date are dated from their name when it carries one; otherwise you
  choose to use the file date or an Undated folder. After an import, the files on the card can
  be moved into an Imported folder. Deleting them from the card is off until you turn it on in
  Settings, and then only removes a file whose copy was re-read and found identical.
- Safe eject for the card, with an honest reason when Windows refuses, and an offer to close the
  Windows helper when it is what holds the card.
- Every confirmation lists all the steps, page by page, including those that will not be done
  and why. Pressing Enter in a confirmation approves nothing.
- If Folio is closed while it changes files, it finishes first. If it is stopped by force, it
  checks what happened when it next opens and says so.

## Known limits

- Only exact copies are found. Photographs that look alike are not.
- No import from a phone. Copy the photos to a folder first.
- Import from a card and Organize on exFAT and FAT32 drives are new in this release and have had
  less real-world testing than the rest. Start with Copy, and leave deleting from the card off.
- When imported files are moved on the card, their sidecar files (.xmp, .thm) stay where they were.
- The installer is not digitally signed yet, so Windows may show “Windows protected your PC”
  on first run (More info, then Run anyway). There is no automatic updater yet: download the
  next version by hand.
- Capture dates are not read from ORF, RW2, CR3 and RAF files.
- Previews of HEIC, AVIF and RAW depend on the image support installed in Windows.
- Cleanup is refused, with the reason, where Windows cannot guarantee a copy can be restored: on
  USB flash drives and SD cards, on exFAT drives, when the Recycle Bin is off or too full, and
  for a file larger than the Recycle Bin.
- Tested on Windows 11. Windows 10 (version 1809 or later) is built for but not yet tested.

## Not in this release

Import from a connected phone, and Folio for macOS. Both are in development and
neither has a release date.
