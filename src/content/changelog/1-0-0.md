## In the beta

- A gallery of every photograph and video in the locations you add, several at once, with a
  timeline of when they were taken.
- Adding a location by dropping a folder on one of the three doors, and Check for changes to
  scan it again.
- Scanning and identification you can stop and resume, even after closing Folio.
- Exact duplicates, judged on content, page by page for large archives. Let Folio choose keeps
  exactly one copy of each photograph, and a copy you mark Keep as backup is never offered for
  removal.
- Cleanup through the Windows Recycle Bin. No permanent deletion.
- Rename in bulk, with every new name shown first, three separators, and numbering per file
  type. Extensions are kept.
- Organize by capture date in four folder styles, optionally sending folders left empty to the
  Recycle Bin.
- Every confirmation lists all the steps, page by page, including those that will not be done
  and why. Pressing Enter in a confirmation approves nothing.
- If Folio is closed while it changes files, it finishes first. If it is stopped by force, it
  checks what happened when it next opens and says so.

## Known limits

- Only exact copies are found. Photographs that look alike are not.
- No direct import from a phone or camera. Copy the photos to a folder first.
- Capture dates are not read from ORF, RW2, CR3 and RAF files.
- Previews of HEIC, AVIF and RAW depend on the image support installed in Windows.
- Cleanup is refused, with the reason, where Windows cannot guarantee a copy can be restored: on
  USB flash drives and SD cards, on exFAT drives, when the Recycle Bin is off or too full, and
  for a file larger than the Recycle Bin.
- Tested on Windows 11. Windows 10 (version 1809 or later) is built for but not yet tested.

## Not in this release

Import from a connected phone or camera, and Folio for macOS. Both are in development and
neither has a release date.
