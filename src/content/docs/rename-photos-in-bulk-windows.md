description: Replace names like IMG_4821 with one meaningful name plus a date, number or letter, preview every new name first, and keep each file's type.

---

Camera names such as `IMG_4821.CR2` tell you nothing about the photograph. Renaming a whole trip
by hand takes hours, and a mistake in the middle is hard to spot. A bulk rename gives every photo
in a set a consistent name in one step.

## Pick a name and a sequence

You type one name, such as `Bali 2019`. Folio adds a sequence after it so every file stays unique:

- **Time.** When each photograph was taken, from the camera: `Bali 2019 2019-08-14 091203`. A
  photograph without a recorded date is left alone.
- **Number.** Counting from one, in the order shown: 001, 002, 003.
- **Letter.** Lettering in the order shown: A, B, C, and AA after Z.

## Pick a separator

The separator goes between the parts of the name: a space, an underscore or a dash.

## Extensions are never touched

Each photograph keeps its own file type. A `.CR2` stays a `.CR2`, a `.JPG` stays a `.JPG`, and a
video stays a video. You type the name without an extension, so a rename cannot turn a RAW file
into something Windows no longer recognizes.

## Rename in bulk with Folio

1. **Add your locations** and let Folio read them. The scan never changes your files.
2. **Open Rename in bulk.**
3. **Type a name** and choose the sequence and the separator.
4. **Check the preview.** Every new name is shown next to the old one before anything changes.
5. **Approve the plan.** Nothing on your drives changes until you do.

## A sensible order

Rename after you have removed extra copies, so you do not spend effort naming files you are about
to delete: [find duplicate photos](/docs/find-duplicate-photos-windows) first, then
[organize by date](/docs/organize-photos-by-date-windows), then rename.
